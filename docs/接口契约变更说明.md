# 接口契约变更说明

按任务要求：公共 HTTP 接口变更在此记录，便于前端联调与回归。

---

## 2026-03-23 — P0-02 Webhook 错误响应

| 项目 | 内容 |
|------|------|
| **接口** | `POST /api/stripe/webhook` |
| **变更类型** | 响应体收紧（不兼容：仅错误场景） |

### 变更说明

- **原行为**：履约逻辑抛错时，响应体为 `{"error": "<内部错误字符串>"}`，可能泄露实现细节。
- **现行为**：HTTP **500**，响应体固定为 `{"error":"Fulfillment failed"}`；详细原因仅服务端日志（含 `eventId`、`sessionId`）。

### 前端 / 集成方注意

- Stripe 重试 Webhook 时不依赖响应 `error` 文案；若自有监控曾解析该字段，需改为依赖 HTTP 状态码或 Stripe Dashboard 投递记录。

### 无变更项

- 验签失败仍为 **400** + `{"error":"Invalid signature"}`。
- 缺少 `stripe-signature` 仍为 **400** + `{"error":"Missing stripe-signature"}`。
- 成功仍为 **200** + `{"received":true}`。
